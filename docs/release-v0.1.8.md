# 仙剑1 H1 v0.1.8（预发布）

在“系统 → 结束游戏 → 系统设置”中加入“按键映射”，可重新指定上、下、左、右、确定、取消。
设置页使用仙剑原来的边框素材、像素字体、选中动画和调色板，保持 480×272 等比显示。

选中动作后按输入，再按新键即可保存；重复绑定会交换两个动作的按键。
跳出可取消改键，支持恢复默认。设置页始终使用 H1 原来的方向、输入和跳出操作，
长按物理输入+跳出仍可退出程序。默认操作保持不变，字母键仅在主动绑定后生效。

按键配置保存到当前 A/B 资源盘的 `h1keys.cfg`，下次启动自动读取。
损坏配置回到默认按键；写入失败会提示重试并保留当前映射。

**本版只需更新 BDA，主资源、视频包和存档均继续使用。**
首次安装可在 [v0.1.7](https://github.com/HelloClyde/BBKH1-pal1/releases/tag/v0.1.7) 下载两个 PAK 资源包。

实际 MIPS BDA 的事件/持续按住输入、交换、恢复默认、A/B 盘保存与新进程读取检查通过。
完整 H1 V1.41 固件模拟器中，已从旧存档进入设置，改用 X/Z 确定/取消后正常退出，
重新启动程序读取相同映射，再恢复默认并退出。尚未进行物理真机测试。
