# 仙剑1 H1 v0.1.7（预发布）

六段过场改用适合 H1 的 H.264 Constrained Baseline 视频编码，AVI 容器保持不变。
`PALVIDEO.PAK` 从 188810064 字节降到 43815104 字节，缩小 76.79%。
保留 288×180、15 fps 和全部原始 PCM 音频样本；六段视频画质 SSIM 为 0.979～0.997。

**升级压缩视频，需要同时替换 `PAL1.bda` 和本版 `PALVIDEO.PAK`。**
设备上的程序仍命名为 `应用\程序\仙剑1.bda`，视频包放在所选 A/B 盘的 `应用\数据\PAL\`。
`PAL9588.PAK`、配置及存档不变，无需重新下载或迁移。
新版程序继续兼容旧 MS Video 1 视频包；旧版程序不支持新版 H.264 包。

参考 H1 飞天影音内置的 H.264/MPEG-4 能力，游戏内使用固定提交的开源 H264BSD 解码器，
不需要跳到其他应用播放。保持原画幅等比显示，并改进视频缩放开销与时间线，避免逐帧计时误差累积。
方向、确定、取消、固定全屏、背景音乐和 A/B 盘选择沿用 v0.1.6。

6385 帧均已在主机上与 FFmpeg 解码结果逐字节核对；实际 MIPS BDA 的新旧六段 AVI 抽样、
原创建模视频的颜色/音频/跳过/重新打开及资源选择等检查通过。
完整 H1 V1.41 固件模拟器中，正式 BDA 完整播放 258 帧与 920 帧的两段片头，
耗时分别为 17203 ms 和 61337 ms，原时间线为 17200 ms 和约 61333 ms；
已捕获实际过场 PCM、读取旧存档并正常退出。尚未进行物理真机测试。
