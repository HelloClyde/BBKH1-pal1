# 仙剑1 H1 v0.1.4（预发布）

适用于 BBK H1 / Y100 V1.41。首次公开发布完整 SDLPAL 原生移植。

- 地图扩大视野，以统一比例显示到 480×272；支持触摸寻路。
- 战斗与 13 类菜单全屏，仙术光标及装备名称对齐。
- 原生音乐、音效、存读档与可选 PAL98 AVI 播放。
- GPT Image 重设计的 H1 风格“仙”字图标，应用名为“仙剑1”。

下载 `仙剑1.bda`，复制到 `A:\应用\程序\仙剑1.bda`。
程序安装 ZIP 只包含程序与说明；独立附件 `PAL9588.PAK` 与 `PALVIDEO.PAK`
复制到 `A:\应用\数据\PAL\`。资源附件由用户的 Steam 安装生成，并附独立校验清单；
也可使用自己的原版数据重新生成。游戏资源保留原权利，不适用源码的 GPL 许可。
必需 `PAL9588.PAK`，视频包 `PALVIDEO.PAK` 可选。已有资源与存档可继续使用。
源码 ZIP 包含应用、固定的 SDLPAL 与 SDK 源码，且附文件哈希清单。
